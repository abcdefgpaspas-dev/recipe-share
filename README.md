# ふたりのレシピ帳

夫婦でレシピを共有・蓄積するための PWA。ビルド不要、依存パッケージなし。

## まず触ってみる（おためしモード）

初回起動の「接続設定」画面にある **「まず試してみる（この端末だけに保存）」** を押すと、
Supabase の設定なしで、サンプル3件が入った状態で使い始められます。
登録・編集・検索・分量換算・「作った」記録まで全部そのまま動きます。
（URL・写真からの自動取り込みだけはサーバーが必要なので使えません）

あとで 設定 → 「Supabase につないで共有する」から共有モードに切り替えられます。
おためしで登録したレシピはこの端末に残りますが、共有側へは自動では移りません。

## 使い方

- **＋ボタン** から 3 通りで登録
  - 🔗 **URL** … レシピページの URL を貼ると、材料と手順が自動で入る
  - 📷 **写真** … 料理本・雑誌・スクショを撮ると AI が読み取る（PC は ⌘V 貼り付けも可）
  - ✏️ **手入力** … ゼロから書く
  - 材料・手順の行は ▲▼ で並べ替え、× で削除できる
  - どの方法でも、最後は同じ編集フォームで確認してから保存する
- **検索** … 料理名・材料・タグ・メモを横断（スペース区切りで AND 検索）
- **登録者の表示** … 一覧カードと詳細に「● りょう」「● ひろみ」と色付きで出る。
  タグの並びにある名前のチップを押すと、その人が登録したレシピだけに絞り込める。
  表示名と色は 設定 画面で各自が決める
- **詳細画面**
  - `×0.5 / ×1 / ×2` で分量を自動換算（「大さじ3」→「大さじ6」）
  - 材料をタップすると打ち消し線（買い物・調理チェック用。端末内のみ）
  - **🍽 作った** で調理ログを記録 → 作った回数と最終調理日が貯まる
    （押し間違えたら「直近の『作った』を取り消す」で戻せる）
  - ★ でお気に入り
- 一度開いたレシピは**オフラインでも閲覧可能**（キッチンで電波が弱くても読める）

## 公開（GitHub Pages）

リポジトリ直下の `index.html` などがそのまま公開されます。
コピー作業は不要で、編集してコミット・プッシュすれば1〜2分で反映されます。

- 公開URL: https://abcdefgpaspas-dev.github.io/recipe-share/
- 設定: Settings → Pages → Branch `main` / フォルダ `/ (root)`

`supabase/` や `SETUP.md` も同じリポジトリに入りますが、公開されて困る情報は含みません
（Supabase の接続情報は各端末で入力する方式のため、ファイルには一切書かれていません）。

## 構成

```
index.html                        画面（HTML + CSS）
app.js                            アプリ本体
sw.js / manifest.webmanifest      PWA（オフライン・ホーム画面追加）
icon-192.png / icon-512.png       アイコン
supabase/schema.sql               テーブル・RLS・Storage の定義
supabase/functions/extract/       URL・画像からレシピを抽出する Edge Function
SETUP.md                          セットアップ手順（最初に読む）
```

- データは Supabase（Postgres）。2 人でリアルタイムに共有される
- 登録者は `recipes.created_by`、表示名と色は `members` テーブル
- 写真は Supabase Storage
- Anthropic の API キーは Edge Function の Secret にだけ置き、ブラウザには渡さない
- Supabase の URL と anon キーは端末の localStorage に保存（初回だけ入力）

## 取り込みのしくみ

URL 取り込みは 2 段構え。

1. ページに `schema.org/Recipe` の JSON-LD があればそれを使う（正確・**API 課金なし**）
2. 無ければ本文テキストを Claude に渡して構造化する

写真取り込みは Claude の画像認識を使います。
